## SECTION 1: BRAND PHILOSOPHY

**Core principle:** Premium feel through restraint, not flash. Every choice should make the property look more valuable, never more produced.

**Three rules that override everything else:**
1. **Subtle beats obvious.** If a viewer notices the edit, the edit failed.
2. **Let the property breathe.** Hold shots 1 second longer than feels natural.
3. **Sound design carries the cinematic feel.** Music + ambient + whooshes = 50% of the "premium" perception.

**What we never do:**
- Fast whip-pan transitions every cut
- Oversaturated colors
- HDR-look glow on everything
- Light leak overlays as a transition
- Catalog-perfect AI furniture that screams "fake"
- Music louder than ambient room tone allows comfort
- Em-dashes in any client communication
- Trendy color grades that will look dated in 2 years

**Voice and tone for any voiceover or written copy:**
- Honest, grounded, never salesy
- Specific over generic ("3,200 sqft" not "spacious")
- Sentences vary in length
- No banned words: leverage, streamline, unlock, harness, elevate, navigate, comprehensive, robust, dive into, level up, foster

## SECTION 2: COLOR GRADE SPECIFICATIONS

### Master LUT philosophy
- Warm shadows (orange/amber tint at -0.3 to -0.5)
- Cool highlights (slight teal at +0.2 to +0.3)
- Natural midtones (no shift)
- Saturation: +5% maximum (never more)
- Skin tones: always neutral, never pushed warm or orange
- Contrast: subtle S-curve, not aggressive
- Lift highlights +0.2 stop for exteriors only

### LUT names by package tier
| Tier | LUT name | Mood |
|---|---|---|
| Starter ($249) | `RMV_Clean_v1.cube` | Bright, natural, clean |
| Pro ($499) | `RMV_Warm_v1.cube` | Warm cinematic |
| Luxury Feature ($1,199) | `RMV_Warm_Luxury_v1.cube` | Rich warmth, deeper shadows, premium feel |

### Per-tier color characteristics

**Starter:** Bright, natural-looking, slight warmth. Buyers should feel "this is clean and well-lit."
- Exposure: +0.0
- Saturation: +0%
- Warmth: +50 Kelvin
- Contrast: +5

**Pro:** Cinematic warmth, controlled shadows. Buyers should feel "this is a real home, but elevated."
- Exposure: +0.0 to +0.2 on exteriors
- Saturation: +3%
- Warmth: +150 Kelvin
- Contrast: +10
- Subtle vignette: -10% corners

**Luxury Feature:** Rich, magazine-quality grade. Buyers should feel "this is aspirational."
- Exposure: +0.2 on hero shots
- Saturation: +5%
- Warmth: +200 Kelvin in living spaces, +50 in bathrooms
- Contrast: +15
- Subtle vignette: -15% corners
- Golden hour tint on exteriors
- Slight teal in shadows (+0.3)

### Color matching rules
- Pick ONE reference frame per project (usually the master bedroom shot)
- All other shots match to that reference
- Use DaVinci's "Color Match" against the reference
- If outdoor and indoor differ heavily, accept the difference (don't force consistency that looks fake)

## SECTION 3: PACING & SHOT DURATION

### Target lengths by package
| Package | Listing video length |
|---|---|
| Photos Only | N/A (stills only) |
| Drone Only | 15-30 seconds |
| Starter | 45-60 seconds |
| Pro | 60-75 seconds |
| Luxury Feature | 90-120 seconds |

### Shot duration rules (the most important section)
**Hold establishing shots longer than feels natural. Always.**

| Shot type | Hold for |
|---|---|
| Drone exterior reveal (opening) | **5-7 seconds** |
| Interior establishing shot | 3.5-4.5 seconds |
| Gimbal walkthrough (full room) | 4-6 seconds |
| Detail close-up (countertop, fixture, art) | 1.5-2.5 seconds |
| Standard interior shot (no movement) | 2.5-3.5 seconds |
| Twilight money shot | 5-8 seconds |
| Pool/backyard hero | 4-6 seconds |
| Transition shot (hallway, stairs) | 2-3 seconds |
| End card | 2-3 seconds |
| Brand bumper / title card | 1.5 seconds |

### Pacing curve (energy arc)
- **First 8 seconds:** Slow, deliberate. Build anticipation.
- **8-30 seconds:** Reveal key spaces (kitchen, master). Medium pace.
- **30-60 seconds:** Lifestyle moments (pool, twilight, details). Slowing down.
- **Last 8 seconds:** Slow exit. End on a held shot or twilight.

### Pacing per tier (the "feel" difference)
**Starter:** Bright, efficient pace. Showcase value quickly. Average shot length 2.5s.
**Pro:** Cinematic, controlled pace. Average shot length 3.5s.
**Luxury Feature:** Slow, deliberate, magazine-style pace. Average shot length 4.5-5s. Let spaces breathe.

## SECTION 5: CAMERA MOVEMENT RULES

### Movement types and when to use them
| Movement | When to use | Cinematic note |
|---|---|---|
| Slow push-in (gimbal forward) | Hero reveals, twilight shots | The signature RMV move |
| Slow dolly (gimbal lateral) | Walk-throughs of long rooms | Maintain constant speed |
| Drone reveal (rise + back) | Property reveal (always opening) | Start tight, pull wide |
| Drone push-in | Hero exterior, twilight | End on the front door |
| Tripod-locked (no motion) | Detail shots, twilight | Let the shot speak |
| Subtle pan (tripod) | Following sight lines | Max 30 degrees |
| Tilt up (gimbal) | Reveal vaulted ceilings | Slow, ending on architectural detail |

### Movement rules
- All movement must be CONSTANT SPEED (no acceleration or deceleration)
- Drone reveals: 4-6 seconds minimum
- Gimbal walks: never faster than a slow human pace
- No whip pans
- No handheld unless intentional (rare, only for TikTok content)
- Subtle stabilization in post if needed

## SECTION 7: MUSIC SYNC RULES

### Sync philosophy
**The hero shot should land on the music's biggest emotional moment.** Build the entire edit around this anchor.

### DaVinci Resolve workflow for beat sync
1. Import music track first
2. Right-click track on timeline -> **Analyze Audio Beat** -> Mark Beats
3. Use sensitivity setting:
   - Starter: medium (more beats, more cuts)
   - Pro: medium-low
   - **Luxury Feature: low (fewer beats, longer holds)**
4. Beats appear as markers on the timeline
5. Cut clips to land on **downbeats** (the strong beats, not the offbeats)
6. Manually adjust 2-4 frames if a cut feels off

### Beat sync rules
- YES - Cut on downbeats (beats 1 and 3 in 4/4 time)
- NO - Cut on offbeats (beats 2 and 4)
- YES - Let some shots span 2 beats (hold for emphasis)
- NO - Cut every single beat (creates exhausting rhythm)
- YES - Sync the FINAL frame change of a transition to the beat, not the start
- NO - Force every cut to a beat (some shots need to breathe)

### "Drop" moment anchoring
- Identify the song's biggest moment (usually 30-50% into the track)
- Place the **hero shot** to land exactly on this moment
- Build everything else around it

### Audio mixing levels
| Element | Level |
|---|---|
| Music (baseline) | -18 dB |
| Music (during dialogue/voiceover) | -25 dB |
| Music (during peak/drop) | -14 dB |
| Ambient room tone | -22 dB |
| Voiceover | -10 dB |
| Whoosh transitions | -14 dB |
| Risers / impacts | -10 dB peak |

## SECTION 8: SOUND DESIGN (SWOOSHES + AMBIENT)

### Whoosh library (the secret sauce)
The premium feel comes 50% from this. Build a library of:

| Sound type | Use case | Length | Recommended source |
|---|---|---|---|
| **Fast whoosh** | Snappy transitions, scene changes | 0.3-0.5s | Krotos Cinematic Whooshes |
| **Slow sweep** | Hero reveals, dramatic transitions | 1.5-3s | Krotos Risers |
| **Subtle whoosh** | Soft cuts between similar shots | 0.5-1s | Editor's Keys Free Pack |
| **Riser** | Building tension toward drop | 2-5s | Krotos Risers |
| **Impact** | Land on the hero shot, end card | Single hit | Pixflow Cinematic SFX |
| **Subtle drone tone** | Background atmosphere | Loop | Artlist Atmospheres |

### Sound design rules
**Use sparingly.** A premium edit uses 4-8 whooshes/SFX MAX in a 90-second video. Overuse = trailer-y, cheap.

| Where to USE sound design | Where NOT to |
|---|---|
| Scene change between rooms | Between every cut in a sequence |
| Drone reveal opening | Mid-walkthrough |
| Twilight reveal | Detail close-ups |
| Hero shot moment | Quiet "breathing" moments |
| End card entrance | Between bedrooms |

### Layered sound design for luxury feel
For each "hero moment" use TWO layers:
1. **Whoosh** (0.5-1s before the cut, sweeping in)
2. **Subtle impact** (frame-perfect on the cut, low EQ, soft)

This creates a "lift + land" effect that feels premium.

### Ambient sound (the missing premium element)
**Always add subtle ambient under the music.** Most amateur edits skip this. Luxury edits never do.

- **Indoor**: subtle room tone, soft house ambience (-22 dB)
- **Outdoor**: distant ambient wind, soft nature ambience (-20 dB)
- **Twilight**: light cricket/evening ambience (-22 dB)
- **Pool**: gentle water ambience (-18 dB during pool shots only)

Source: Artlist Atmospheres, Freesound.org (verify licensing)

## SECTION 9: TRANSITIONS

### Transition types and when to use
| Transition | Use case | Frequency |
|---|---|---|
| **Hard cut** | 90% of edits | Default |
| **2-frame crossfade** | Between scenes (room to room) | When shots feel jarring |
| **Match cut** | Architectural shapes / motion | Rare, when it works perfectly |
| **Whoosh-aided cut** | Hero moments, scene change | 4-8 per video |
| **Slow dissolve (12 frames)** | Twilight reveal, dramatic moments | 1-2 max per video |
| **Speed ramp (slight slowdown)** | Hero shot entry only | 1 per video max |

### Banned transitions
- Whip pan transitions (overused, dated)
- Light leak overlays (cheap)
- Glitch transitions (wrong vibe)
- Lens flare zooms (amateur)
- Any "trendy" transition that'll look dated in 12 months

### The "no transition" rule
**Most cuts should be HARD CUTS with no effect.** Transitions are flavor, not the meal. If the editor in doubt: hard cut.

## SECTION 10: AI GENERATION (HIGGSFIELD) RULES

### When AI generation is allowed
| Use case | AI allowed? |
|---|---|
| Brand intro/outro graphics | YES |
| Abstract motion graphics | YES |
| Stylized transitions (not realistic property) | YES |
| Agent name card animation | YES |
| Twilight conversion of EXISTING shot | YES (with disclosure to client) |
| Virtual staging of EMPTY rooms | YES (with disclosure + MLS rules) |
| Sky replacement | YES (with disclosure) |
| AI-generated property footage | NEVER for client deliverables |
| AI footage of buildings that don't exist | NEVER |
| Replacing real interior with generated interior | NEVER |
| Adding features (pool, furniture) that don't exist | ONLY for marketing demos clearly disclosed |

### HiggsField prompt rules (to make AI look NOT AI)

**The 2026 trend:** buyers reject "catalog-perfect" AI imagery. They want realistic, lived-in, slightly imperfect spaces.

#### Universal HiggsField prompt principles
1. **Always specify imperfection** - "slight wear on the rug," "one cushion slightly out of place"
2. **Always specify natural lighting** - "afternoon sunlight through west window," not "studio lighting"
3. **Always specify scale references** - "couch sized for 2 adults," not just "sectional"
4. **Specify materials precisely** - "walnut wood, brushed brass hardware," not "luxury furniture"
5. **Include environmental details** - "subtle reflection on hardwood floor," "soft shadows from blinds"
6. **Reference real interior design styles, not "luxury"** - "transitional modern with mid-century accents," not "luxurious"
7. **Add atmospheric details** - "soft dust motes in sunbeam," "slight haze of warm light"

#### Bad vs good HiggsField prompts

**Bad (looks AI):**
> "Luxury living room with modern furniture, perfect lighting"

**Good (looks real):**
> "Living room interior, transitional modern style, 16ft ceilings with exposed beams. Linen sectional sofa in oatmeal color seating 4 adults. Vintage Persian-style rug, slightly off-center, showing minor wear pattern. Walnut coffee table with a single hardcover book and ceramic vase with eucalyptus. Afternoon sunlight from west-facing window creating soft shadows from sheer linen curtains. Slight dust motes visible in sunbeam. Hardwood floors with subtle reflection. Camera at 5'8" height, 35mm lens equivalent, slight wide angle. Photorealistic, magazine quality (Architectural Digest style)."

#### Furniture generation prompt library

**Living room (transitional modern):**
> "Living room interior, transitional modern style, neutral palette (warm whites, oatmeal, walnut, brass accents). One linen sectional seating 5 adults positioned facing a stone fireplace. One mid-century leather lounge chair at angle. Walnut coffee table 6ft long. Persian-style area rug 8x10, off-center toward fireplace, mild patina. Cream sheer curtains framing windows. Single tall potted fiddle leaf fig in corner. Two ceramic vases on coffee table, one with dried branches. Sunlight from upper left, soft shadows. Photorealistic interior design photograph, slightly imperfect styling, lived-in feel. Architectural Digest aesthetic, NOT catalog-perfect."

**Master bedroom (luxury hotel):**
> "Master bedroom, luxury boutique hotel aesthetic. Upholstered linen bed frame, king size, with crisp white duvet and 4 pillows (2 standard, 2 European). Faint wrinkle in duvet near foot, not perfectly made. Soft taupe linen throw blanket draped naturally. Two matching nightstands in walnut with brushed brass lamps. Single ceramic vase with white peonies. Wide plank oak hardwood floors with neutral wool area rug under bed. Sheer linen curtains, sunlight diffusing through. Subtle texture on walls (limewash or grasscloth feel). Photorealistic, Architectural Digest interior, lived-in but elegant. Not overly styled."

**Kitchen (transitional chef's):**
> "Chef's kitchen interior, transitional modern with classical undertones. Quartz waterfall island 10ft long, light gray with subtle veining. Walnut wood cabinetry with brushed brass hardware on lower cabinets. White perimeter cabinets with shaker doors. Subway tile backsplash 4x8 in warm white with light gray grout. One vintage brass faucet over a single farmhouse sink. Three pendant lights with seeded glass over island. Bar stools in oatmeal linen, two of them (not perfectly aligned). One cutting board on island with a small bowl of lemons and a copper kettle. Soft natural light from window over sink. Photorealistic, slightly lived-in, not staged. Magazine quality (Kinfolk style)."

#### Negative prompts (what to avoid in HiggsField)
Always add these to negative prompts:
- "Catalog perfect"
- "Studio lighting"
- "Over-saturated"
- "CGI render"
- "Video game graphics"
- "Cartoon"
- "Stock photo"
- "Mannequin posing"
- "Perfect symmetry"
- "Sterile"
- "Showroom"
- "Hyperreal"
- "Unrealistic glow"

### Realism enhancement settings (HiggsField)
- Model: Veo 3.1 or Sora 2 for video, Imagen 4 for stills
- Resolution: 4K minimum
- Aspect ratio: match the delivery (16:9 for horizontal, 9:16 for vertical)
- Generation iterations: 5-8 variants, pick the most "imperfect-looking"
- Post-processing in DaVinci: subtle film grain (8%), slight noise (3%), match the master LUT

## SECTION 11: VIRTUAL STAGING (FURNITURE GENERATION)

### When to virtual stage
| Scenario | Stage? |
|---|---|
| Empty room in a vacant listing | Yes (with disclosure) |
| Furnished but dated/cluttered | Maybe (digital de-clutter only) |
| Already well-staged | No (don't fix what's not broken) |
| Outdoor spaces | Usually not (too risky) |

### Virtual staging principles for 2026
**The mistake everyone makes:** generating "perfect" rooms that look obviously AI.

**The 2026 standard:** generated rooms that look LIVED-IN.

### Style by buyer demographic
| Buyer profile | Stage in this style |
|---|---|
| Young professional ($249-500k) | Transitional modern with warm minimalism |
| Family home ($500-900k) | Contemporary family-friendly, slight Scandinavian |
| Luxury single-family ($900k-2M) | Transitional luxury with mid-century accents |
| Luxury estate ($2M+) | Mediterranean, modern coastal, or architectural |

### Staging tools (in order of quality 2026)
1. **VirtualStagingAI.app** ($15-30/photo, best quality)
2. **ApplyDesign.io** ($7-39/photo, fast iteration)
3. **Boxbrownie.com** ($32/photo, hand-finished option)
4. **HiggsField** (free with subscription, requires good prompting)

### Disclosure rule
**ALWAYS include in delivery email:**
> "This listing includes [N] virtually staged photos. Original empty room photos available on request. NTREIS guidelines compliant."

Get realtor written acknowledgment before delivery.

## SECTION 18: THE NORTH STAR

When the AI is unsure, defer to these:

1. **Will this make the property look more valuable?** If no, cut it.
2. **Does this feel intentional or trendy?** If trendy, cut it.
3. **Would Architectural Digest publish this?** If yes, keep it.
4. **Can the viewer breathe?** If no, slow it down.
5. **Does the music tell the viewer when to feel something?** If yes, the sync is right.

When in doubt: **less is more, slower is better, restraint over flash.**
